# Automatisiertes Einkommens-Setup

Eine Android-App mit Backend-API für automatisierte Einkommens-Verwaltung und -Optimierung.

## 📋 Projektübersicht

Dieses Projekt entwickelt eine umfassende Lösung zur Verwaltung und Optimierung von Einkommensströmen mit:
- Native Android App (Kotlin + Jetpack Compose)
- Backend-API (FastAPI/Express/Ktor)
- Intelligentes Empfehlungssystem
- Offline-First Architektur
- DSGVO-konforme Datenverwaltung

## 🚀 Schnellstart

### Voraussetzungen
- Android Studio Arctic Fox oder neuer
- JDK 11+
- Docker & Docker Compose (für Backend)
- Git

### Installation

```bash
# Repository klonen
git clone https://github.com/loopwaveeeeee/sabsteckapi.git
cd sabsteckapi

# Backend starten (TBD)
cd backend
docker-compose up -d

# Android App öffnen (TBD)
# Öffne das android/ Verzeichnis in Android Studio
```
